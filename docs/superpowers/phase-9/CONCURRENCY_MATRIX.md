**Date:** 2026-09-15

## Review conclusion

No new concurrency hole was demonstrated by this consolidation. The critical write paths use one of four explicit mechanisms: row locking, optimistic revision checks, finite leases, or unique/deterministic idempotency keys. Provider ambiguity is deliberately modeled instead of being hidden behind automatic retries.

The highest-risk boundary remains shipment spending: `purchase_outcome_unknown` must never trigger an automatic second purchase merely because local persistence is uncertain. Existing shipment service/migration tests and the Phase 9 contracts continue to preserve that rule.

The dashboard is intentionally different: it is a read snapshot, not an eventually-consistent browser aggregation. A single server RPC chooses one `as_of` instant so all period metrics are evaluated against the same cutoff.
